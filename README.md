# PCOS Detection using Deep Learning

This repository contains deep learning implementations and experiments for detecting Polycystic Ovary Syndrome (PCOS) from ultrasound images.

## Models Evaluated
- **Basic CNN**
- **CNN with Data Augmentation**
- **VGG16 (Feature Extraction)**
- **VGG16 (Fine-Tuning + Data Augmentation)**

## Contents
- `PCOS.ipynb`: Jupyter notebook containing model architectures, training routines, and evaluation metrics.
